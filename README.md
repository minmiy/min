## uw-metrics — 신계약 심사지표 산출기

`uw-metrics/index.html`: 신계약 마감 데이터(엑셀/CSV)를 올리면
1. 데이터 이상(공란, 날짜 순서, 상태 불일치, 증번 중복, 날짜 형식)을 행 단위로 점검하고
2. 3일이내 터치율 · 자동심사율 · 신계약 처리건수 · 심사결과 통계를 표준 기준으로 산출하고
3. 전월 대비 증감, 기준 초과 색상 표시, 요약 코멘트(기준 문안 + AI 다듬기)를 만든 뒤
4. 결과표를 엑셀(요약/채널별/심사결과/심사자별/데이터점검/원본_점검표시/산출기준)로 내려받습니다.
