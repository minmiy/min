## uw-metrics — 신계약 심사지표 산출기

`uw-metrics/index.html`: 신계약 마감 데이터(엑셀/CSV, 여러 달이 한 파일에 있어도 됨)를 올리면
1. 계약일자 연월로 마감월을 나누고, 고른 달과 전월의 지표 4종을 산출합니다 — ① 3일이내 터치율(경과일수 = 심사시작일 − 최초심사일, 영업일/달력일) ② 자동심사율 ③ 채널별·실제심사자별 처리 건수 ④ 심사결과 통계(정상인수 표준/조건부, 반송, 청철)
2. 점검 규칙 E1~E5(오류, 지표 제외)와 W1~W10(경고, 지표 포함)으로 행 단위 점검을 하고, 파일에 검증용 계산열(마감월~점검_경고코드)이 있으면 행별로 대조합니다
3. 요약 코멘트를 주제별로 만들고(기준 문안 + AI 다듬기) 결과표를 엑셀로 내려받습니다

같은 파일의 `공휴일`·`기준표` 시트(3일 기준, 영업일/달력일, 미결 포함, 허용 채널·계약상태)를 자동으로 반영합니다.
예시 데이터는 제공받은 가상 더미 워크북(신계약마감 1,200건, 2026.08~09)에 추이 확인용 가상 10개월(2025.10~2026.07, 증번 G로 시작)을 페이지에서 생성해 붙인 것입니다. 더미 워크북만 올렸을 때 산출 결과가 정답지 ①~⑦과 모두 일치하는 것을 확인했습니다.

② 심사자별 현황은 고른 마감월의 지표별 1위 심사자(3일이내 터치율·인심사율·처리 건수·정상인수율, 이름과 건수)와 최근 12개월 월별 처리 건수 히트맵 표를 보여줍니다. 데이터 점검 결과는 화면 맨 끝에서 펼쳐 볼 수 있습니다.

배포
- Claude 아티팩트: https://claude.ai/artifact/6TWkjEZqyTq4zBkEWU4XM2 — AI 코멘트 다듬기(`sample`)와 저장 확인 창(`downloads`) 사용
- Vercel: 정적 파일 그대로 배포(빌드 불필요). `/`는 `vercel.json`에서 `/uw-metrics/`로 이동. 단독 페이지에서는 엑셀이 브라우저 다운로드로 저장되고, AI 다듬기 버튼은 숨겨지며 기준 문안 자동 생성만 동작

`uw-metrics/index.html`은 아티팩트 게시 형식과 같은 완전한 HTML 문서(doctype 포함)라서 두 곳에 같은 파일을 그대로 씁니다. 첫 줄의 `<!doctype html>…<body>` 골격은 아티팩트가 인식하는 형식이니 바꾸지 마세요.

## 지표 챗봇

화면 오른쪽 아래 **지표 챗봇** 버튼. 현재 화면의 지표·심사자별 현황·점검 요약(행 단위 데이터 제외)을 근거로 답합니다.

- **Vercel**: `api/chat.js` 서버리스 함수가 OpenRouter를 호출합니다. 키는 서버에만 있고 브라우저로 나가지 않습니다.
  - `OPENROUTER_API_KEY` (필수): Vercel 프로젝트 환경변수
  - `OPENROUTER_MODEL` (선택): 기본값 `nvidia/nemotron-3-super-120b-a12b:free`. 다른 무료 Nemotron 예: `nvidia/nemotron-3.5-lightning:free`, `nvidia/nemotron-3-ultra-550b-a55b:free`
  - 같은 백엔드로 요약 코멘트의 'AI로 보고 문안 다듬기'도 동작합니다.
- **Claude 아티팩트**: `/api/chat`이 없으므로 Claude(`sample` 기능)로 답합니다.
- OpenRouter 무료 모델은 제공사가 입력을 로그·학습에 쓸 수 있습니다. 실제 심사자 이름 등 민감한 데이터를 보낼 때는 OpenRouter 계정의 데이터 정책 설정을 확인하세요.
