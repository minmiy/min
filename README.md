## uw-metrics — 신계약 심사 마감 현황

`uw-metrics/index.html`: 신계약 마감 데이터(엑셀/CSV, 여러 달이 한 파일에 있어도 됨)를 올리면
1. 계약일자 연월로 마감월을 나누고, 고른 달과 전월의 지표 4종을 산출합니다 — ① 3일이내 터치율(경과일수 = 심사시작일 − 최초심사일, 영업일/달력일) ② 자동심사율 ③ 채널별·실제심사자별 처리 건수 ④ 심사결과 통계(정상인수 표준/조건부, 반송, 청철)
2. 점검 규칙 E1~E5(오류, 지표 제외)와 W1~W10(경고, 지표 포함)으로 행 단위 점검을 하고, 파일에 검증용 계산열(마감월~점검_경고코드)이 있으면 행별로 대조합니다
3. **월마감 보고서** 탭에서 A4 두 장 보고서를 작성합니다. 1쪽 '1. 전체 심사지표 리뷰'(터치율 · 자동심사율 · 처리 건수 · 심사결과), 2쪽 '2. 심사자별 심사현황'(월별 처리 건수 · 터치율·심사결과) · '3. 전체 리뷰' · '4. 개선사항 / 당월 특이사항'이며 소주제마다 표와 코멘트가 있습니다. 개선사항은 기준 미달 심사자·채널, 반송률 초과, 원천 데이터 공란에서 자동으로 초안을 만들고, 당월 특이사항에는 영업일·공휴일을 넣습니다. 화면에서 각 쪽이 A4에 맞는지 바로 보여줍니다. 표는 산출 결과로 자동 채우고, 문장은 화면에서 바로 고치거나 AI로 다듬은 뒤 Word(.docx)·엑셀로 내려받습니다. Vercel에서는 인쇄·PDF 저장도 됩니다

같은 파일의 `공휴일`·`기준표` 시트(3일 기준, 영업일/달력일, 미결 포함, 허용 채널·계약상태)를 자동으로 반영합니다.
예시 데이터는 제공받은 가상 더미 워크북(신계약마감, 전속 채널 제외 945건, 2026.08~09)에 추이 확인용 가상 10개월(2025.10~2026.07, 증번 G로 시작)을 페이지에서 생성해 붙인 것입니다. 채널은 GA·방카·TM만 허용하며, 전속 채널 행은 E4(허용값 위반)로 지표에서 제외됩니다.

② 심사자별 현황은 고른 마감월의 지표별 1위 심사자(3일이내 터치율·인심사율·처리 건수·정상인수율, 이름과 건수)와 최근 12개월 월별 처리 건수 히트맵 표(심사자만, 자동심사·공란 제외)를 보여줍니다. 데이터 점검 결과는 '점검 결과' 탭에 있습니다(탭에 제외 행 수 표시).

배포
- Claude 아티팩트: https://claude.ai/artifact/6TWkjEZqyTq4zBkEWU4XM2 — AI 코멘트 다듬기(`sample`)와 저장 확인 창(`downloads`) 사용
- Vercel: 정적 파일 그대로 배포(빌드 불필요). `/`는 `vercel.json`에서 `/uw-metrics/`로 이동. 단독 페이지에서는 엑셀이 브라우저 다운로드로 저장되고, AI 다듬기 버튼은 숨겨지며 기준 문안 자동 생성만 동작

`uw-metrics/index.html`은 아티팩트 게시 형식과 같은 완전한 HTML 문서(doctype 포함)라서 두 곳에 같은 파일을 그대로 씁니다. 첫 줄의 `<!doctype html>…<body>` 골격은 아티팩트가 인식하는 형식이니 바꾸지 마세요.

## 지표 챗봇

화면 오른쪽 아래 **지표 챗봇** 버튼. 현재 화면의 지표·심사자별 현황·점검 요약(행 단위 데이터 제외)을 근거로 답합니다.

- **Vercel**: `api/chat.js` 서버리스 함수가 OpenRouter를 호출합니다. 키는 서버에만 있고 브라우저로 나가지 않습니다.
  - `OPENROUTER_API_KEY` (필수): Vercel 프로젝트 환경변수
  - `OPENROUTER_MODEL` (선택): 기본값 `nvidia/nemotron-3-super-120b-a12b:free`. 다른 무료 Nemotron 예: `nvidia/nemotron-3.5-lightning:free`, `nvidia/nemotron-3-ultra-550b-a55b:free`
  - 같은 백엔드로 요약 코멘트의 'AI로 보고 문안 다듬기'도 동작합니다.
- **Claude 아티팩트**: `/api/chat`이 없으므로 Claude(`sample` 기능)로 답합니다.
- OpenRouter 무료 모델은 제공사가 입력을 로그·학습에 쓸 수 있습니다. 실제 심사자 이름 등 민감한 데이터를 보낼 때는 OpenRouter 계정의 데이터 정책 설정을 확인하세요.

## 기준 관리

**기준 관리** 탭에서 지표 정의와 점검 규칙을 바꿀 수 있습니다. '기준 적용'을 누르면 산출 화면·보고서·엑셀에 모두 반영됩니다.

- 지표 정의: 터치율(N일, 영업일/달력일, 분모, 날짜 공란 처리), 자동심사율(자동/인심사 결과값, 공란 처리), 처리 건수(미결 포함), 심사결과(정상·반송·청철·미결 상태값 매핑, 반송률 분모), 목표값, 보고서용 정의 문구
- 점검 규칙: 규칙별 사용 여부, 오류(지표 제외)/경고(지표 포함) 등급, 설명 문구. 열 · 조건(공란/목록에 없음/목록에 있음) · 값으로 규칙 추가
- 기준은 브라우저에 저장되며, `.json`으로 내보내고 불러와 팀이 같은 기준을 쓸 수 있습니다. 기본값으로 되돌리기 가능

## 월마감 보고서 작성 흐름

1. 보고서는 **초안**으로 만들어집니다(우측 상단 '초 안' 도장).
2. 표 아래 주석·제목·작성 부서·작성자는 언제든 눌러서 고칠 수 있고, 마감월·파일별로 브라우저에 저장됩니다. 재산출·기준 변경 후에도 고친 내용은 유지되며, '초안 다시 만들기'만 초기화합니다.
3. **최종 확인**을 누르면 확인 일시·작성자가 찍힙니다. 이후 내용을 고치면 자동으로 다시 초안이 됩니다.
4. **출력**: Vercel 등 일반 브라우저에서는 인쇄 창(PDF 저장 가능), Claude 아티팩트 안에서는 A4 PDF 파일로 저장. Word(.docx)도 상태(초안/최종 확인)를 함께 담습니다.

## 검증 가능성 (PRD 평가 대응)

- **기준 경고**: ① 심사지표 맨 위에 목표 미달·기준 초과(빨강)와 전월 대비 변동 큼(노랑) 항목을 모아 보여주고, 색상 범례를 함께 표시합니다.
- **그래프**: ①에 월별 처리 건수 막대, 터치율·자동심사율·반송률 추이 선 그래프(마우스를 올리면 값 표시), ②에 심사자별 히트맵.
- **기능 자가진단** (점검 결과 탭): 현재 데이터로 실제 .xlsx를 만들어 업로드와 같은 경로로 다시 읽고, 결과표 엑셀을 생성해 시트를 다시 읽어 확인하며, 색상 경고·그래프·전월 비교·보고서 생성 여부를 근거와 함께 통과/실패로 보여줍니다.
